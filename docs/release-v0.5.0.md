# iAttend v0.5.0

This release adds assessment tracking and refreshes the app experience across its main screens.

## What's new

- Schedule tests linked to a class and exams scheduled independently.
- Configure assessment weightage, record attempts and marks, and track weighted results separately from attendance percentages.
- View assessments alongside classes in the calendar and browse a subject's schedule in a calendar view.
- Manage holidays in a calendar view and review scheduled extra classes in history.
- Delete an individual timetable class occurrence, with a choice to keep or remove its linked test.
- Use the new **Rectangle Expandable** navigation style.
- Improved contrast and surface separation in light, dark, and AMOLED themes, alongside refined assessment forms, navigation, empty states, and calendar scrolling.

## Upgrade

Install the APK attached to this GitHub release. Existing app data remains on the device during a normal app update.
