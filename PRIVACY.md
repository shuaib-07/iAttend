# Privacy Policy

iAttend is fully offline and collects nothing.

- **No account.** There is no sign-up, sign-in, or user identifier of any kind.
- **No analytics, no crash reporting, no telemetry.** The app does not include Firebase, Google Analytics, Crashlytics, Sentry, or any similar SDK.
- **No data leaves your device**, with one narrow exception: if you choose a remote avatar in Profile settings, the app fetches that avatar image from [DiceBear](https://dicebear.com) over the network. This is the *only* network request iAttend ever makes, it only happens if you opt into a remote avatar, and it sends nothing about you — just a request for an image.
- **All your data** — subjects, timetables, attendance records, exams, settings — is stored locally in the app's own database on your device. Exporting a backup writes a JSON file to a location you choose; importing reads one back in. Neither operation touches any server.
- **Permissions** requested (notifications, exact alarms, boot-complete) are used solely to schedule and show local reminder notifications on your device. None of them involve sending data anywhere.

If this ever changes, this file will be updated first, in the same commit as the change.
