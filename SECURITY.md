# Security Policy

## Reporting a Vulnerability

If you find a security issue in iAttend, please open a [GitHub issue](../../issues/new) describing it. Since this is a small, fully offline, personal-data-only app (no accounts, no backend, no network access beyond an optional avatar image fetch — see [PRIVACY.md](PRIVACY.md)), the attack surface is limited to the app itself and the local device.

Please include:
- Android version and device (if relevant)
- Steps to reproduce
- What you'd expect to happen vs. what actually happens

There's no bug bounty — this is a free personal project — but reports are genuinely appreciated and will be fixed as soon as possible.
